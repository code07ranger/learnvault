# LearnVault AI - Notebook Summarizer & Key Points 🧠

A full-stack application built with **React**, **Node.js / Express**, and **OpenAI API** designed to summarize study notebooks into clean, user-friendly key points, executive overviews, and actionable study takeaways.

---

## 🌟 Key Features

1. **User-Friendly Key Points Breakdown**
   - Automatically parses raw notes and extracts structured, bolded key concepts.
2. **Executive Overview**
   - 2-3 sentence high-level summary callout box.
3. **Key Definitions & Action Items**
   - Identifies important terms with clear definitions and recommended study tasks.
4. **Copy & Markdown Export**
   - 1-click copy summary text or download as structured `.md` document.
5. **Summarized Vault History**
   - Persistent local storage to browse, search, and review past notebook summaries.

---

## 🚀 How to Run

### 1. Start Backend Server
```bash
cd server
npm start
```
*Runs Express on `http://localhost:5000`*

### 2. Start React Frontend
```bash
cd client
npm run dev
```
*Runs React Vite on `http://localhost:3000`*
